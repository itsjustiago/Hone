MediaPipe Hands models (CoreML) used by Hone's hand mouse
=========================================================

Files
  hand_detector.mlmodelc            palm detector (input 192x192)
  hand_landmarks_detector.mlmodelc  hand landmarks (input 224x224, 21 points)

Provenance
  CoreML conversion: https://github.com/VimalMollyn/Mediapipe-Hands-PyTorch-CoreML
  (the "fasthands" port). The conversion code is MIT licensed.
  The weights are derived from Google's MediaPipe hand_landmarker.task.
  Both models are stored here in fp16, compiled for CoreML.

Regenerating the compiled models
  Get the .mlpackage files from the repository above, then:

    xcrun coremlcompiler compile hand_detector.mlpackage <output dir>
    xcrun coremlcompiler compile hand_landmarks_detector.mlpackage <output dir>
